# ZiCAD 二次开发说明

## 推荐仓库简介

> 基于 CADCraft 二次开发的轻量二维 CAD，新增内置 AI 绘图助手、图框识别与批量 PDF、图纸目录生成、本地 DXF→DWG 导出及中文网页体验，保留 MCP 自动化入口。

English:

> A CADCraft-derived 2D CAD workflow with an integrated AI assistant, frame-based PDF output, sheet indexes, local DXF-to-DWG export and Chinese web UI improvements, retaining the upstream MCP interface.

建议标签：`cad`、`2d-cad`、`rust`、`webassembly`、`egui`、`dxf`、`dwg`、`mcp`、`ai-assistant`、`pdf`。

## 原创增量与继承边界

| 模块 | 上游基础 | 本次二开内容 | 关键文件 |
|---|---|---|---|
| CAD 核心 | 几何、对象、命令、图层、布局、渲染与文件框架 | 作为 ZiCAD 扩展底座，品牌及集成适配 | `crates/geom/`、`doc/`、`engine/`、`render/` |
| AI 助手 | 可调用的 CAD 命令核心 | 新增对话、配置、附件、命令反馈、自动/确认执行和面板交互 | `crates/ui-egui/src/ai.rs` |
| 批量出图 | 现有 PDF 渲染和导出基础 | 新增图框识别、候选选择和按框分页 PDF 工作流 | `frames.rs`、`sheets.rs` |
| 图纸目录 | 普通绘图与文字命令 | 新增字段推断及目录线框/文字生成 | `sheets.rs` |
| DWG | 上游原生 `acadrust` 桥接 | 新增网页导出命令、本地 HTTP 服务和下载流程 | `dwg_export.rs`、`tools/dev-proxy.py` |
| MCP | 已有 MCP 协议、工具集、CLI 与桌面控制桥 | 名称适配、保留接口和二开工作流说明 | `crates/mcp/`、`apps/cadcraft-cli/` |
| 中文与主题 | 上游 i18n/主题框架 | 简繁扩展、中文 UI 字体、部分术语与主题体验 | `i18n/`、`theme.rs`、`assets/fonts/` |
| 网页集成 | 上游 WASM 应用和宿主桥 | 图片附件处理、开发服务和资源复制、ZiCAD 界面 | `apps/cadcraft-web/` |

不能将“整个 CAD 引擎、MCP 协议实现、DWG 编解码器”表述为本次新增原创。可以突出“基于开放命令架构，完成 AI、出图和交付的一体化工作流”。

## 可用于发布页的功能亮点

### 让 AI 接近真实 CAD 操作

让模型不只回答绘图问题，还能按照约定生成 CAD 命令。ZiCAD 负责执行和结果反馈，用户可以选择确认后执行或自动执行，将自然语言需求接入现有绘图流程。

### 把出图组织从单次操作变成批量流程

从图框候选到页面选择，再到多页 PDF 和图纸目录，减少逐张圈选与重复整理。检测规则当前强调可复核、可调整，不宣称自动理解任意施工图。

### 将网页编辑结果交付为 DWG

通过本地转换服务，把浏览器里的当前图纸导出为多个目标版本的 DWG，连接轻量编辑和常见工程交付格式。

### 保留外部代理与脚本入口

在可视化编辑之外，保留 MCP 和命令行入口，使用户和开发者可以围绕绘图核心组合自动化流程。后续扩展应继续遵守统一命令体系。

## 验证口径

- AI：真实网页 DeepSeek 对话已验证；并非所有预设平台/模型都已实测。
- AI 交互：8 项测试覆盖发送、无 Key 提示、关闭、网络错误、快捷键、短视口长聊天、回答/token/耗时反馈等。
- DWG 导出：2 项 UI 层原生测试；3 项 HTTP/转换测试；网页真实下载样例已读回验证。
- 图框/PDF：`frames_flow.rs` 验证示例图框检测及 PDF 数据生成，也记录了建筑轮廓可能误识别为图框的边界。
- 批量打印文件命名的 WASM 不兼容计时调用已修正为 `web-time`；已补充工程对话框首次打开、检测、关闭和重新打开测试，并验证单图框真实网页 PDF 下载；多图框网页交互仍需继续回归。
- 此处只列明确核对的专项测试，不代表整个仓库已通过全部 CI。

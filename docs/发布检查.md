## 建议在公开上传前复核

### 功能

- [ ] 在全新目录从源码重新构建网页和转换器，按 README 启动。
- [ ] 用不含个人 Key 的新浏览器环境验证“未配 Key”提示。
- [ ] 用自有测试 Key 验证一次 AI 对话，然后确认截图与文档不含 Key。
- [ ] 用多个图框验证网页批量选择、PDF 页数、顺序、尺度与文字。
- [ ] 检查图纸目录的候选图名、图号和版别；确认生成对象可以撤销和编辑。
- [ ] 用一份自己的脱敏 DXF 导出 DWG，并用独立 CAD 软件打开复核。
- [ ] 不将示例图验证外推为全部工程文件兼容。

### 素材与来源

- [ ] 复核中文字体的原始下载来源、修改/子集生成记录及附带许可。现有字体的 name 表标识为 Noto Sans CJK SC，内嵌版权为 Adobe 2014–2021，项目中附有 OFL 文本；本次没有重新下载原字体核验完整来源链。
- [ ] 在真正分发桌面版之前替换或审核旧图标、DMG 背景和其他上游品牌素材；不要把上游图标宣传为 ZiCAD 自有设计。
- [ ] 保留 LICENSE、NOTICE、ATTRIBUTION 和依赖信息。
- [ ] 如图纸、图片或字体来源不清楚，先从公开包移除，再补证据。

### 仓库

- [ ] 确认仓库名称、发布分支、作者信息和仓库网址；材料中未虚构你的 GitHub/Gitee 地址。
- [ ] 检查文件清单，尤其是新增但尚未被 Git 跟踪的 AI/打印/DWG 模块与字体。
- [ ] 再做一次密钥与私人文件检查；启发式扫描不是无泄漏保证。
- [ ] 先手动上传源代码；继承的 CI/Release 工作流审核后再启用。
- [ ] 本次压缩包不含 `.git` 历史。若直接推送原工作区，另查历史提交中的凭据与大文件。

### 公网服务

- [ ] 开发代理与转换接口不能直接作为匿名公网服务。
- [ ] 增加身份认证、权限、限流、转发目标限制、文件隔离和资源控制。
- [ ] 设计 AI Key 与用量管理；为图片和图纸数据发送提供明确说明。
- [ ] 上线后再标注实际域名和可用服务；现阶段不写“公共云服务已上线”。

## 可用发布说明模板

### ZiCAD 开发预览版

本版本在 CADCraft 开源二维 CAD 核心上，新增内置 AI 对话与命令反馈、图框候选识别、按图框批量 PDF、图纸目录和网页 DXF→DWG 导出，完善简繁中文与网页交互，并保留 MCP 自动化入口。

当前适合本地体验与开发者验证。MCP 底层、原生 DWG 桥接和 CAD 核心继承上游；云存储、团队协作和公网多用户服务尚未提供。图框识别、字体和复杂工程图纸兼容性仍在完善。

验证记录应写具体测试命令和样例，不使用未经测量的“最快”“全兼容”“零损失”等宣传。

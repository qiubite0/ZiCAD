# 图纸版本与 LSP 应用加载

桌面版支持通过 AP / APPLOAD 或“工具 → 加载 LSP 应用（AP）”选择 .lsp 文件，也可以将文件拖入窗口。加载后在命令行输入脚本定义的命令；仅运行可信来源脚本。当前为内置 AutoLISP 解释器，不承诺所有 AutoCAD 扩展函数兼容；不支持 ARX、FAS、VLX 二进制插件。

保存参数接受 2000—2026 年份，自动映射为实际文件格式：2000—2003、2004—2006、2007—2009、2010—2012、2013—2017、2018—2026。新建图纸的默认格式在“文件 → 默认保存格式”设置；已打开图纸默认保留原格式，另存时可指定版本。

AutoCAD 2018—2026 共用 AC1032（2018 DWG 格式），没有独立的“2026 DWG 格式”。兼容年份不等于所有代理对象、行业对象和扩展数据均可无损往返；应以实际图纸复核。
